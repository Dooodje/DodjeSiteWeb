# Référencement dans les stores (ASO) : App Store et Google Play

Dernière mise à jour : 26 novembre 2026. Fiche iOS : id6743447215. Android : `xyz.dodje.app`.

## Ce qui fait monter une app dans les stores en 2026

**App Store (Apple)**
- Seuls quelques champs sont indexés : **nom (30 caractères)**, **sous-titre (30)**, **champ mots-clés caché (100)** et, depuis juin 2025, **le texte des captures d'écran** (lu par OCR). La description n'est pas indexée.
- Le nom pèse le plus lourd, puis le sous-titre et le champ mots-clés. Un mot déjà présent dans le nom ou le sous-titre ne sert à rien dans le champ mots-clés : Apple combine les mots de ces champs entre eux.
- Le comportement compte autant que les mots : téléchargements, taux de conversion de la fiche, notes et avis, rétention (Apple l'a confirmé dans une publication de recherche en mars 2026).
- Les **pages produit personnalisées** (jusqu'à 70) peuvent se classer sur les mots-clés qu'on leur attribue depuis juillet 2025. Les **événements in-app** apparaissent aussi dans la recherche.
- Les liens externes ne comptent pas pour le classement Apple : le site aide seulement en envoyant des visiteurs qui téléchargent.
- Changer le nom, le sous-titre ou les mots-clés demande de soumettre une nouvelle version de l'app. Le texte promotionnel (170 caractères) se change à tout moment mais n'est pas indexé.

**Google Play**
- Indexés : **titre (30)**, **description courte (80)**, **description longue (4 000)**.
- Google le dit lui-même : bourrer la description courte de mots-clés n'aide pas et nuit à la conversion. Il faut écrire pour les gens, avec le mot-clé principal dans les 2 premières phrases de la longue, puis 3 à 5 fois au total, jamais en liste.
- Comptent aussi : installations, rétention, désinstallations, plantages (Android Vitals), notes, réponses aux avis, mises à jour régulières.
- Les liens vers la fiche Play depuis d'autres sites aident un peu (l'effet est discuté) : chaque article du site pointe déjà vers les stores.
- Pas de bourrage : « #1 », « meilleur », « gratuit » dans le titre sont interdits par les règles Play.

## Ce qui se passe hors des fiches

- **Avis** : la demande de note dans l'app (`src/services/storeReview*` dans DodjeAPP) doit arriver après un moment positif (niveau gagné, victoire dans l'Arène), jamais au premier lancement. Répondre aux avis sur Google Play, surtout aux négatifs, en moins de 48 h.
- **Mises à jour régulières** : une version toutes les 2 à 4 semaines, avec des notes de version lisibles.
- **Site → stores** : chaque article se termine par « Jouer à Dodje » vers la fiche ; l'accueil a les deux badges. Plus le site attire de lecteurs, plus il envoie de téléchargements, ce qui aide le classement dans les deux stores.
- **Suivi** : la tâche planifiée « Suivi marque Dodje » vérifie chaque lundi la position de Dodje sur ces mots-clés (`docs/routine-marque.md`).
